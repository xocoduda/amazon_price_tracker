# Amazon Price Tracker

## Competencias técnicas

- Automatización del seguimiento de precios de un producto mediante Python y Selenium WebDriver
- Extracción de precios de una página web dinámica utilizando selectores CSS
- Configuración de un precio objetivo para decidir cuándo se debe enviar una alerta
- Programación de comprobaciones automáticas a una hora determinada con `datetime`
- Envío de notificaciones por correo electrónico con SMTP y conexión segura TLS
- Gestión de credenciales y configuración sensible mediante variables de entorno con `python-dotenv`
